# Personal Finance Platform Template

> ⚠️ Este repositório é um **template** de uma plataforma de controle financeiro pessoal.
> Ele contém **arquitetura, padrões e decisões técnicas**, e **não** dados financeiros reais.

## Visão geral
Este projeto tem como objetivo servir como base para a construção de uma plataforma
de controle de gastos e investimentos pessoais, com foco em **evolução**, **clareza de domínio**
e **escalabilidade**.

O repositório foi desenhado para refletir decisões que seriam tomadas em um
ambiente profissional, mesmo sendo um projeto pessoal.

## O que este projeto é
- Um template arquitetural
- Um estudo de caso de decisões técnicas
- Um ponto de partida para sistemas financeiros pessoais
- Um repositório focado em documentação e arquitetura

## O que este projeto NÃO é
- Um aplicativo pronto para uso
- Um sistema com dados financeiros reais
- Um produto final

## Princípios
- Separação clara de domínio
- Arquitetura evolutiva
- Decisões documentadas
- Segurança e privacidade por padrão

## Estrutura do projeto

- apps/ → aplicações (ex: web, api)
- packages/ → domínio, UI e código compartilhado
- docs/ → documentação e decisões arquiteturais


## Segurança e privacidade
Este repositório **não contém dados financeiros reais**.
Todos os exemplos utilizam dados simulados (mock).
